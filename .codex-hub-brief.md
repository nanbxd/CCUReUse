# CaspianHub: главная и публикация мероприятий

Режим: главная — Read / Operate; редактор событий — Operate. Работа расширяет существующую стилистику колледжа. Реальные данные обязательны, при их отсутствии — честные пустые состояния.

## Direction contract

THESIS: общий вход в жизнь сообщества, где афиша и маркет равноправны. Главная начинается с нейтрального сообщения CaspianHub, без старого манифеста шеринга.

OWN-WORLD: знак колледжа с текстовым CaspianHub; белое пространство, оранжевый акцент, чёткие границы, крупные заголовки Manrope. Тёмная тема сохраняет иерархию.

STORY: пользователь узнаёт портал, просматривает свежие афиши, затем товары. Создатель события заполняет структурированный документ и сразу видит предпросмотр.

FIRST VIEWPORT: компактная навигация; нейтральный заголовок слева, ссылки разделов справа; ниже большие загруженные баннеры событий с ручным переключением. Маркет следует ниже.

FORM: расширение существующего мира, кодовая реализация по заданной пользователем структуре. seed: none (unavailable). Редактор — секции данных с постоянным предпросмотром, без декоративного рекламного блока.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance


## Finish review

Главная, маркет и редактор реализованы по контракту. Проверены реальные состояния в браузере на телефоне, планшете и десктопе, обе темы, загрузка баннера и публикация. DESIGN.md обновлён по результату. Новых растровых ассетов нет; используемый знак колледжа и тестовые изображения взяты из существующего репозитория. Вердикт: готово к ревью.
